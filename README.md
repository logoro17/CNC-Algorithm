# 🛠️ C++ Driven Multi-Format CNC Path Optimizer

A high-performance GUI application designed to optimize CNC G-Code cutting/travel paths ($G00$ non-cutting moves) using custom algorithms written in C++ and exposed to a modern Python/PyQt5 frontend.

## 📌 Overview

Traditional CNC toolpaths generated by basic CAM software often include unnecessary rapid moves ($G00$), leading to increased wear on CNC components and longer total machining times. 

This project solves Traveling Salesperson Problem (TSP) variants for grouped G-Code contours by executing high-speed optimization algorithms in native **C++** and visualizing the optimized path dynamically using **PyQt5** & **Matplotlib**.

---

## ✨ Features

* **⚡ Native C++ Processing Engine:** Optimization algorithms execute in milliseconds via Pybind11 / C++ extension modules.
* **📂 Broad File Format Support:** Drag & Drop support for `.gcode`, `.ngc`, `.nc`, `.tap`, `.g`, `.cnc`, and `.txt`.
* **🧩 Multi-Algorithm Optimization:**
  1. **Nearest Neighbor (Greedy):** Fast deterministic path ordering.
  2. **2-Opt Local Search:** Eliminates crossing travel paths.
  3. **Simulated Annealing (SA):** Metaheuristic optimization to escape local minima.
  4. **Genetic Algorithm (GA):** Evolutionary approach for complex multi-contour toolpaths.
* **🎛️ Dynamic Hyperparameter Tuning:** Tweak parameters (e.g., Population Size, Cooling Rate, Max Iterations) per algorithm directly from the UI (`⚙ Config`).
* **📊 Visual & Metric Comparison:**
  * Interactive Matplotlib canvas with path color-coding ($G00$ Rapid vs $G01$ Cutting).
  * Real-time benchmark reports showing total distance saved (mm) and execution time (ms).
* **🖥️ Resizable Splitter UI:** Dynamic workspace with a draggable vertical bar separating the visual graph and terminal execution logs.
